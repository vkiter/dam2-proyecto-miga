## 📌 Descripción

M.I.G.A. ayuda a planificar la alimentación diaria, reducir el desperdicio y apoyar a los productores locales. Las aplicaciones actuales organizan recetas o dietas, pero no contemplan la sostenibilidad ni la conexión con el comercio de proximidad.

La aplicación integra cuatro módulos:

- 🥫 **Despensa e inventario:** control de stock, caducidades, historial de compras y gastos.
- 📍 **Buscador de proximidad:** pequeños productores, mercados municipales y comercios tradicionales, priorizando producto local y de temporada.
- 🛒 **Pedidos y listas de la compra:** listas dinámicas y encargos con recogida en tienda o envío a domicilio.
- 📅 **Planificador de recetas:** recetas editables y compartibles vinculadas a un calendario semanal.

## 🌿 Flujo de ramas

- `main` → código estable. Protegida: solo se actualiza mediante Pull Request aprobada.
- `develop` → rama de integración.
- `feature/<nombre-tarea>` → una rama por issue, se fusiona en `develop` mediante Pull Request.

Los commits siguen **Conventional Commits** (`feat:`, `fix:`, `docs:`, `chore:`, `test:`, `refactor:`).
